# PC Health Check CLI

A command-line project that checks a PC's health and generates a detailed report. It is intended to help users understand a computer's condition by collecting and presenting relevant health information.

## Project goals

- Read health-related status information from a PC.
- Produce a detailed, easy-to-review report.
- Support remote execution in the future through a service hosted on AWS.

## Planned workflow

1. Run the CLI to collect health information from a PC.
2. Generate a report from the collected results.
3. In a future version, allow an AWS-hosted server to request checks remotely and retrieve their reports.

## Project status

The project is under development. AWS-based remote execution is a future goal, not a currently available feature.
